# Custom home banner

Administrators can open Settings and use **Custom home banner** at the bottom of the page. Choose a PNG or JPEG up to 2 MB, optionally enter a title and description, select a position from 1–6, and save. Landscape artwork around 1920 × 1080 works best; the banner fills the available area and can crop on narrow screens.

The entry rotates with the featured media, including after refreshing the home recommendations. Position 1 appears first. Positions beyond the available media place the custom entry last. It also works with an empty media library. Clear **Show custom entry** and save to hide it while retaining its image and text.

This is one installation-wide entry, visible to every signed-in viewing profile, so use artwork suitable for all profiles. It has no playback action. It is stored in the application database and included in server-state backups.
